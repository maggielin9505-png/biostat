# 社區居民疾病流行與飲用水來源關聯性調查與生物統計分析

本專案收錄流行病學調查資料分析腳本、生物統計檢定運算、與調查報告書產出成果。

## 專案內容說明

- **`calc_stats.py`**：資料載入、交叉分析、卡方檢定、Relative Risk (RR) 與 Odds Ratio (OR) 統計計算腳本。
- **`generate_report_word.py`**：產出排版完整的 Word 調查報告書 (`.docx`) 自動化腳本。
- **`parse_doc.py`**：原始數據文件萃取與結構化清理腳本。
- **`調查報告書_流行病學與水質分析.md`**：完整文字版流行病學與水質關聯性調查報告。
- **`113007008-橘郡異常事件調查報告書.docx` / `.pdf`**：格式化正式調查報告書。
- **`調查情報20260331.xlsx` / `1022.doc`**：原始調查資料與原始報告素材。
- **`spss_sub_analysis.txt` / `extracted_1022_doc.txt` / `cleaned_1022_doc.txt`**：中間分析產出與清理文字。

## 核心結論

本調查針對目標社區全體受訪居民共 669 名進行流行病學調查與生物統計分析：
1. **疾病與死亡率**：社區罹病率為 76.98%（515人），個案致死率（Case Fatality Rate, CFR）高達 100.0%。
2. **飲用水暴露**：飲用深井水（Deep well）為導致居民患病及死亡的單一決定性危險因子（$RR = 11.905$，$OR = 5,475.214$，$p < 0.001$）。
3. **人口學特徵**：性別與年齡分組與患病及死亡無統計學顯著關聯。
